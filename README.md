# Практическая работа № 2

## Вариант B

### 1. Скрипт report.sh

Скрипт принимает путь к каталогу и уровень сообщений `ERROR` или `WARN`.

Функции:

* подсчёт сообщений по модулям;
* сортировка по убыванию количества сообщений;
* ограничение количества результатов с помощью `--top N`;
* проверка существования каталога;
* вывод справки при отсутствии аргументов с кодом возврата 1.

Примеры запуска:

```bash
./report.sh ./logs ERROR
./report.sh ./logs WARN
./report.sh ./logs ERROR --top 2
```

Формат тестовых логов:

```text
2026-10-28 ERROR auth Не удалось войти
```

В этой строке второе поле обозначает уровень сообщения, а третье — модуль.

### 2. Программа hello.py

Программа принимает путь к файлу, читает его содержимое и выводит размер в байтах.

Запуск:

```bash
python3 hello.py sample.txt
```

### 3. Анализ системных вызовов Python

Трассировка создана командой:

```bash
strace -f -o trace.txt python3 hello.py sample.txt
```

Общее количество системных вызовов: **ЗАМЕНИ СВОИМ ЧИСЛОМ**.

Количество вызовов `read()`: **ЗАМЕНИ СВОИМ ЧИСЛОМ**.

Количество вызовов, относящихся к чтению `sample.txt`: **ЗАМЕНИ РЕАЛЬНЫМ ЧИСЛОМ**.

Остальные системные вызовы необходимы для запуска и работы интерпретатора Python, загрузки модулей и библиотек, управления памятью, открытия файлов и выполнения других операций операционной системы.

### 4. Сравнение cat и Python

Команда для `cat`:

```bash
strace -c cat sample.txt
```

Количество системных вызовов `cat`: **ЗАМЕНИ СВОИМ ЧИСЛОМ**.

Команда для Python:

```bash
strace -c -f python3 hello.py sample.txt
```

Количество системных вызовов Python: **ЗАМЕНИ СВОИМ ЧИСЛОМ**.

#### Вывод

Программа `cat` предназначена для чтения и вывода содержимого файла. Python выполняет дополнительные операции, связанные с запуском интерпретатора, загрузкой модулей и выполнением программы.

Поэтому количество системных вызовов Python обычно выше. Не все вызовы Python связаны непосредственно с чтением исследуемого файла: значительная часть является накладными расходами интерпретатора и его окружения.
